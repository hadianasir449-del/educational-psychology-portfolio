# Student Learning Support Assistant

## Project Overview

This project is an educational support tool designed to help students reflect on their learning needs and find practical study-support strategies.

## Purpose

The purpose of this project is to connect basic Educational Psychology concepts with practical student learning support.

## Key Areas

- Learning difficulties
- Study habits
- Learning strategies
- Student motivation
- Time management
- Learning support

## Important Note

This is an educational support project. It is not a substitute for a qualified counselor, psychologist, teacher, or other professional.
